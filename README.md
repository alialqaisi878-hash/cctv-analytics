# نظام تحليل الكاميرات (CCTV Analytics)

برنامج يشتغل على حاسبتك بالشغل، يكتشف الكاميرات الموجودة على الشبكة، يكشف ويتتبع الأشخاص، يحسب كم واحد دخل وطلع من كل باب، يقيس الزحمة ومدة البقاء بكل منطقة، وبيه مساعد ذكاء اصطناعي (Claude) يحلل الحركة ويكتب تقارير يومية بالعربي.

## شنو يسوي

| الميزة | التفاصيل |
|---|---|
| اكتشاف الكاميرات | يبحث بالشبكة عن كاميرات ONVIF ويفحص منافذ RTSP (554 و 8554)، ويقترح رابط RTSP حسب نوع الكاميرا (هيكفيجن، داهوا، يونيفيو، تي بي لينك، ريولينك) |
| كشف وتتبع الأشخاص | YOLO11 + ByteTrack، يشتغل على المعالج (CPU) أو كرت الشاشة (GPU) |
| عدّ الداخل والطالع | خط افتراضي على كل باب، سهم على الفيديو يوضح اتجاه "الدخول" |
| المناطق ومدة البقاء | مثل الاستقبال، منطقة الانتظار، منطقة العمل: عدد الزيارات ومتوسط وأطول مدة بقاء |
| لوحة تحكم ويب | بث مباشر، أرقام اليوم، رسم بياني حسب الساعة وآخر 7 أيام، تصدير CSV |
| المساعد الذكي | تسأله بالعربي ("شنو أكثر ساعات الزحمة؟") ويجاوب من الأرقام الحقيقية، ويكتب تقرير يومي تلقائي |
| تنبيهات بالصور | خارج الدوام، زحمة، كاميرا مفصولة، ظهور شخص معيّن. كل تنبيه وياه صورة تنفتح بالضغط عليه، ونافذة منبثقة مع صوت |
| التعرف على الوجه (اختياري) | يتعرف بس على الأشخاص اللي تسجلهم بصفحة "الأشخاص" (صورة من الحاسبة أو التقاط من كاميرا)، ويطلع جدول حضور: أول وآخر ظهور |
| إرسال للواتساب / تلگرام | التنبيه مع صورته يوصل لرقمك عن طريق Green-API أو UltraMsg (واتساب) أو بوت تلگرام |

### تحسينات أضفتها
- **يشتغل بدون إنترنت وبدون مفتاح API**: إذا ماكو مفتاح Claude، يطلع تقرير أساسي تلقائي.
- **بيانات تجريبية**: `--demo-data` يعبّي أسبوع بيانات حتى تجرب اللوحة والمساعد قبل ربط الكاميرات.
- **إعادة اتصال تلقائية** إذا انقطعت الكاميرا.
- **تحذير من أخطاء العد**: إذا الداخلين أكثر بكثير من الطالعين بنهاية اليوم، ينبهك أن الخط يحتاج تعديل.
- **حماية اللوحة بكلمة سر** (اختياري).
- **ملف CSV** لكل يوم تفتحه بـ Excel.

## الخصوصية (مهم)
- التعرف على الوجه **مطفّي افتراضياً**. إذا شغلته، يتعرف بس على الأشخاص اللي أنت تسجلهم، والباقي يطلعون "غير معروف". كل شي يصير على حاسبتك، وما تطلع صور للإنترنت (إلا إذا فعّلت إرسال التنبيهات للواتساب).
- بلّغ الموظفين إن النظام يتعرف على الوجوه وسجّل بس اللي موافقين. نص تنبيه المراقبة بالرئيسية يتحدث تلقائياً حسب الإعدادات.
- الوجوه **مموّهة** بالبث المباشر للأشخاص غير المعروفين (تقدر تطفيها من الإعدادات).
- ما ينحفظ فيديو أبداً. ينحفظ أرقام، وصورة وحدة لكل تنبيه (تقدر تطفيها).
- البيانات وصور التنبيهات تنمسح تلقائياً بعد **30 يوم** (`retention_days`).
- المساعد الذكي يذكر أوقات الحضور كأرقام، وما يحكم على شخص أو أدائه.
- ننصح تحط لافتة واضحة بمكان العمل إن المكان مراقب، وتبلغ الموظفين، وتتأكد من القوانين المحلية. نص التنبيه يظهر أعلى اللوحة وتقدر تعدله بـ `config.yaml`.

## التنصيب على حاسبتك

### المتطلبات
- ويندوز 10/11 أو لينكس أو ماك.
- **Python 3.10 أو أحدث**: من [python.org](https://www.python.org/downloads/). بويندوز أشّر على "Add Python to PATH" أثناء التنصيب.
- الحاسبة لازم تكون على نفس شبكة الكاميرات.
- معالج حديث يكفي لكاميرا أو ثنتين. لـ 4 كاميرات أو أكثر يفضّل كرت شاشة NVIDIA.

### الطريقة الأسهل (ويندوز): ملف التنصيب
1. نزّل **`CCTV-Analytics-Setup.exe`** من [صفحة الإصدارات](https://github.com/alialqaisi878-hash/cctv-analytics/releases/latest).
2. شغّله واضغط Next. إذا طلع تحذير Windows SmartScreen اضغط **More info ← Run anyway** (لأن الملف مو موقّع بشهادة مدفوعة).
3. التنصيب ينزّل Python والمكتبات تلقائياً (5-15 دقيقة، يحتاج إنترنت). ما يحتاج صلاحيات مدير.
4. يطلعلك اختصار **CCTV Analytics** على سطح المكتب وبقائمة ابدأ. تفتحه وينفتح البرنامج بنافذة خاصة بيه (تسد النافذة يتوقف البرنامج).
   - بقائمة ابدأ أكو كذلك: **Settings** (يفتح config.yaml)، **Repair** (يعيد تنصيب المكتبات)، و**Uninstall**.
   - تگدر تختار أثناء التنصيب إن البرنامج يشتغل وحده ويا تشغيل الويندوز.

### التحديثات (أونلاين، بدون إعادة تنصيب)
البرنامج يفحص GitHub كل 6 ساعات. إذا أكو نسخة جديدة:
- يطلع شريط أزرق باللوحة بيه زر **تحديث الآن**، أو
- يتنصب وحده **خارج أوقات الدوام** حتى ما يوگف العد.
إعداداتك (`config.yaml`) وإحصائياتك (`data/`) ما تتأثر. تگدر تطفي التحديث التلقائي من `updates.auto_install`.

### الطريقة اليدوية (ويندوز)
1. فك الملف المضغوط بمجلد، مثلاً `C:\cctv-analytics`.
2. دبل كلك على **`start.bat`**. أول مرة ينصّب المكتبات (5-10 دقائق، يحتاج إنترنت) وينزّل موديل YOLO تلقائياً.
3. افتح المتصفح على: **http://localhost:8000**

### الخطوات (لينكس / ماك)
```bash
cd cctv-analytics
./start.sh
```
ثم افتح http://localhost:8000

### تشغيل يدوي (بدل السكربت)
```bash
python -m venv .venv
# ويندوز:  .venv\Scripts\activate      لينكس/ماك:  source .venv/bin/activate
pip install -r requirements.txt
python run.py
```

### فيديو التجربة
أول تشغيل يستخدم فيديو تجريبي `samples/people.mp4`. إذا مو موجود، نزّله من:
https://github.com/intel-iot-devkit/sample-videos/raw/master/people-detection.mp4
وحطه بمجلد `samples`.

### تجربة اللوحة ببيانات وهمية
```bash
python run.py --demo-data     # يعبّي أسبوع بيانات تجريبية
python run.py                 # شغّل اللوحة وشوف الرسومات والتقارير
```
(امسح `data/cctv.db` قبل الاستخدام الحقيقي حتى تبدي بأرقام نظيفة.)

## ربط الكاميرات

كلشي من داخل البرنامج، صفحة **الكاميرات**:

1. اضغط **بحث عن الكاميرات بالشبكة**. يطلعلك IP كل كاميرا موجودة.
2. اضغط **إضافة** يم الكاميرا، اكتب اسم المستخدم وكلمة المرور (نفس مال تطبيق الكاميرا) واضغط إضافة. البرنامج يلگي رابط البث وحده (هيكفيجن، داهوا، يونيفيو، تي بي لينك، ريولينك وغيرها).
   - إذا عندك جهاز تسجيل (NVR/DVR): ضيف IP الجهاز واختار **رقم القناة** لكل كاميرا.
   - إذا البحث ما لگاها: **إضافة يدوية بالـ IP**.
3. تنفتح صورة الكاميرا: اضغط نقطتين لرسم **خط العد** عند الباب. السهم يبيّن اتجاه الدخول، وإذا معكوس فعّل **اعكس الاتجاه**.

الكاميرات المضافة تنحفظ بـ `data/cameras.yaml`، والإعدادات اللي تغيرها من صفحة **الإعدادات** بـ `data/settings.yaml`. مفتاح Claude API ينحط من صفحة الإعدادات كذلك.

للمتقدمين: تگدر تكتب الكاميرات والمناطق (zones) يدوياً بـ `config.yaml`، والأمثلة موجودة بداخله.

### نصائح لدقة أعلى
- الكاميرا تكون فوق الباب وتطل لتحت بزاوية، مو بمستوى الوجه.
- إضاءة كافية؛ الكاميرات الليلية (أبيض وأسود) تشتغل بس الدقة أقل.
- للدقة الأعلى بحاسبة قوية: `model: "yolo11s.pt"`.
- إذا المعالج تعبان: قلل `process_fps` إلى 5، أو استخدم الـ sub-stream للكاميرا (بهيكفيجن `Channels/102`).

## المساعد الذكي (Claude أو OpenAI)
1. طلع مفتاح API من [console.anthropic.com](https://console.anthropic.com) (Claude، يبدي بـ `sk-ant-`) أو من [platform.openai.com](https://platform.openai.com/api-keys) (OpenAI، يبدي بـ `sk-`).
2. حطه بـ **الإعدادات ← المساعد الذكي**. البرنامج يعرف نوع المفتاح تلقائياً.
3. من صفحة التقارير اسأل أي سؤال، أو اضغط **أنشئ التقرير**. التقرير اليومي يطلع تلقائياً الساعة `daily_report_time`.

المساعد يشوف **أرقام فقط** (مو فيديو ولا صور). تحليل الفيديو نفسه (كشف الأشخاص والوجوه) يصير على حاسبتك بدون إنترنت.

## إرسال التنبيهات للواتساب
1. سوّي حساب على [green-api.com](https://green-api.com) أو [ultramsg.com](https://ultramsg.com) واربط رقم واتساب (يفضّل رقم ثاني مو رقمك الشخصي) بمسح الـ QR.
2. انسخ رقم الـ Instance والـ Token من لوحتهم.
3. بالبرنامج: **الإعدادات ← إرسال التنبيهات**، اختر الخدمة، الصق الرقمين، واكتب رقمك اللي تريد توصله التنبيهات (مثل `07701234567`)، واحفظ.
4. اضغط **أرسل رسالة تجربة**.

للتلگرام: سوّي بوت من `@BotFather`، حط الـ token، وحط رقم المحادثة (chat id).

### n8n / Webhook (مثلاً فلو شكيب)
1. بـ n8n سوّي عقدة **Webhook** (Method: POST)، فعّل الفلو، وانسخ الـ **Production URL**.
2. بالبرنامج اختر **n8n / Webhook**، الصق الرابط، وتگدر تحط رمز سري يوصل بالهيدر `X-CCTV-Token` حتى الفلو يتأكد منه.
3. كل تنبيه يوصل JSON بيه: `message`, `kind`, `time`, `camera`, `location` (المخطط والنقطة), `person` (`name`, `erp_id`, `job`), و`image_base64` لصورة التنبيه. بـ n8n استخدم **Convert to File** (من base64) حتى تدز الصورة للواتساب.
4. إذا فعّلت **دز تحركات الموظفين**، يوصل حدث `kind: "location"` كل ما موظف مسجّل ينشاف بكاميرا ثانية أو يرجع بعد غياب.

## الخريطة وأماكن الموظفين
- من **الخريطة ← إضافة مخطط** ارفع صورة مخطط المكان، وحط كل كاميرا بمكانها (اختار الكاميرا واضغط على المخطط، أو اسحبها).
- كل موظف مسجّل بصفحة الأشخاص يطلع عند آخر كاميرا تعرفت على وجهه، و"موجود" إذا انشاف خلال آخر 15 دقيقة.
- بصفحة الأشخاص اضغط **تعديل** وحط الوظيفة ورقم الموظف بالـ ERP.
- الـ ERP أو n8n يگدر يقرا المواقع من `GET /api/locations` (أو `?erp_id=E-102` لموظف واحد).

## الإعدادات المهمة (`config.yaml`)
| الإعداد | المعنى |
|---|---|
| `working_hours` | أوقات وأيام الدوام (للتنبيهات والتقارير). الأيام: الاثنين=0 ... الأحد=6 |
| `alerts.max_occupancy` | تنبيه إذا عدد الأشخاص بكاميرا تجاوز هذا الرقم (0 = مطفي) |
| `privacy.retention_days` | كم يوم تنحفظ البيانات |
| `privacy.blur_people` | تمويه الوجوه بالبث |
| `server.password` | كلمة سر للوحة |
| `server.host` | `127.0.0.1` = بس من نفس الحاسبة، `0.0.0.0` = من أي جهاز بالشبكة (مثلاً موبايلك على `http://IP-الحاسبة:8000`) |

## نشر نسخة جديدة (للمطوّر)
غيّر الرقم بملف `app/version.py` (مثلاً من `1.0.0` إلى `1.1.0`) وادمج التعديل بـ `main`.
GitHub Actions يبني `CCTV-Analytics-Setup.exe` و`cctv-analytics-update.zip`، يجرّب التنصيب على ويندوز نظيف، وينشر الإصدار. الأجهزة المنصّبة تتحدث وحدها.

## مشاكل شائعة
- **الكاميرا offline**: جرّب الرابط بـ VLC، تأكد من اسم المستخدم وكلمة السر، وإن RTSP مفعّل من إعدادات الكاميرا.
- **البحث ما لگه كاميرات**: بعض الراوترات تمنع البث المتعدد (multicast). جرّب `--subnet` برينج شبكتك، أو خذ الـ IP من تطبيق الكاميرا/جهاز التسجيل.
- **بطيء**: قلل `process_fps` أو `imgsz: 480`، أو استخدم sub-stream.
- **الأرقام مو دقيقة**: عدّل مكان الخط حتى يكون على الأرضية بالضبط عند الباب، وبعيد عن مكان وقوف الناس.

## English summary
Local-first people analytics for workplace CCTV: ONVIF/RTSP discovery, YOLO11 + ByteTrack person tracking,
per-door in/out line counting, zone occupancy and dwell time, after-hours/crowding alerts, a FastAPI web
dashboard, and a Claude-powered analyst (tool use over the aggregate SQLite DB) for Q&A and daily reports.
Privacy by default: no face recognition, head blurring in the live view, no frames stored, aggregate-only
data with automatic retention. Setup: `pip install -r requirements.txt && python run.py`, open http://localhost:8000.
